# LSTM-XGBoost AQI Forecasting

This repository contains the implementation of a Sequential Hybrid LSTM-XGBoost framework for Air Quality Index (AQI) forecasting across multiple Indian metropolitan cities.

## Dataset

The dataset used in this study is publicly available:

https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india

Download `city_hour.csv` and place it inside:

data/city_hour.csv

before executing the scripts.
